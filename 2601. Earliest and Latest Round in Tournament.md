## 💡 Problem - Earliest and Latest Round in Tournament

There are `n` players in a tournament. In each round:

- The i-th player from the start plays against the i-th player from the end.
- The winner advances.
- If the number of players is odd, the middle player advances automatically.
- After each round, the winners are reordered in **ascending** order by their original player number.

You are given two players: `firstPlayer` and `secondPlayer`. These are the **strongest players** and will always win unless they face each other.

Return the **earliest** and **latest** round numbers in which they could meet.

---

### 🔐 Constraints:

- `2 <= n <= 28`
- `1 <= firstPlayer < secondPlayer <= n`

---

### ✅ Example:

**Input:**  
`n = 11, firstPlayer = 2, secondPlayer = 4`  
**Output:**  
`[3, 4]`

**Input:**  
`n = 5, firstPlayer = 1, secondPlayer = 5`  
**Output:**  
`[1, 1]`

---

### ✅ Code (Python3)

```python
from typing import List
from math import inf

class Solution:
    def earliestAndLatest(self, n: int, fp: int, sp: int) -> List[int]:
        def dfs(x, y, total):
            if x == y: return (1, 1)
            if x > y: return dfs(y, x, total)
            mn, mx = inf, -inf
            for i in range(1, x + 1):
                for j in range(x - i + 1, y - i + 1):
                    s = i + j
                    if x + y - total // 2 <= s <= (total + 1) // 2:
                        a, b = dfs(i, j, (total + 1) // 2)
                        mn = min(mn, a + 1)
                        mx = max(mx, b + 1)
            return (mn, mx)

        return list(dfs(fp, n - sp + 1, n))
